---

### 2. Описание тестируемого модуля
Для тестирования была создана библиотека `MathLibrary`, в которую вынесена логика с трех страниц приложения:
* **Page1 (Complex Expression)**: Вычисление сложного арифметического выражения с использованием `Math.Exp`, `Math.Sqrt` и `Math.Atan`.
* **Page2 (Conditional Logic)**: Алгоритм с разветвлением, использующий три режима функций (`sinh`, `sqr`, `exp`) в зависимости от выбора пользователя.
* **Page3 (Tabulation)**: Логика циклического вычисления значений функции для построения графиков и таблиц.

---

### 4. Реализация Unit-тестов
В тестовом проекте `TestProject1` реализовано **16 автоматизированных тестов**.

#### Структура тестов:
1. **Проверка точности (Assert.AreEqual)**: Сравнение результата функции с эталонным значением (с точностью до 0.001).
2. **Проверка условий (Assert.IsNotNull/IsTrue)**: Подтверждение работоспособности логических веток `if-else`.
3. **Тестирование исключений (ExpectedException)**: Проверка того, что приложение корректно выбрасывает `ArgumentOutOfRangeException` при недопустимых входных данных (например, деление на ноль или корень из отрицательного числа).
